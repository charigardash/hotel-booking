# Hotel Booking Service

A Spring Boot 3 / Java 17 backend for property discovery, booking, payment, and cancellation.
Built as a clean, modular, in-memory implementation with a focus on domain modelling and extensibility.

## 🚀 How to Run

1. Ensure you have **Java 17+** and **Maven** installed.
2. Run the application:
   ```bash
   mvn spring-boot:run
